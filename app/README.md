# tambo — application web

Interface Svelte 5 + Vite de [tambo](../README.md).

```bash
npm install
npm run build:wasm   # compile crates/tambo-wasm → src/wasm/
npm run dev          # serveur de dev
npm run build        # build production → app/dist/
```

Consulter le [README principal](../README.md) pour l'architecture, le CLI et le guide utilisateur.
